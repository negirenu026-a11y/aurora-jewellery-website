# Áurea Jewellery – 3D jewellery showcase (React + Tailwind CSS)

A premium showcase website for a Brazilian jewellery brand. Interactive 3D ring (Three.js), category filter, WhatsApp enquiry buttons with pre-filled messages and a contact form. No cart, payments or login.

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # outputs the dist/ folder
npm run preview    # test the production build
npm run build:demo # optional: single self-contained HTML file in dist-demo/
```

## Configuration (one file: `src/config/site.js`)
| What to change | Where |
|---|---|
| WhatsApp number (country code + area code + number, digits only) | `siteConfig.whatsapp.number` |
| Default WhatsApp message | `siteConfig.whatsapp.defaultMessage` |
| Instagram / Facebook | `siteConfig.social` |
| Email, address, opening hours | `siteConfig.contact` |
| Show or hide prices | `siteConfig.showPrices` |
| Products, prices and categories | `products` and `categories` arrays |

Each product's WhatsApp message is built by `productMessage()` in the same file, e.g. *"Hello! I'm interested in the **Aurora Ring** (Rings)..."*.

### Replace the illustrations with real photos
1. Put your photos in `public/products/` (e.g. `public/products/aurora-ring.jpg`).
2. In the product, set `image: '/products/aurora-ring.jpg'`.
3. If `image` is `null`, the site uses the automatic vector illustration.

**Free / licensed images:** use the brand's own photography (best), or libraries with free licences such as Unsplash, Pexels and Pixabay, checking each photo's licence. This project ships no third-party photos: every jewel shown is an illustration or 3D scene generated by code.

## Social media
- **Instagram:** the grid uses illustrations that link to your profile. For a live feed, create a free widget with Behold.so, Elfsight or SnapWidget and paste its embed code into `src/components/Social.jsx`.
- **Facebook:** set `social.facebook.embed: true` to show the official Page plugin. The page must be public.

## Deploy for free on Vercel
**Option A – via GitHub (recommended)**
1. Create a GitHub repository and push the project (`git init`, `git add .`, `git commit`, `git push`).
2. Go to vercel.com, sign in with GitHub and click **Add New → Project**.
3. Import the repository. Vercel detects Vite automatically (Build: `npm run build`, Output: `dist`).
4. Click **Deploy**. In about a minute the site is live at `your-project.vercel.app`.
5. For a custom domain: **Settings → Domains**.

**Option B – command line**
```bash
npm i -g vercel
vercel          # answer the prompts (accept the defaults)
vercel --prod   # publish to production
```

## Structure
```

  config/site.js        <- number, socials, products (edit here)
  components/           <- Hero, HeroScene (3D), Collections, ProductCard, Products,

  hooks/useTilt.js      <- 3D card tilt
```

## Performance
- The 3D scene loads on demand (lazy), pauses off-screen and caps the pixel ratio.
- Respects `prefers-reduced-motion` (static scene, no animations).
- SVG illustrations (no image weight); real photos use `loading="lazy"`.
- If WebGL is unavailable, the site shows the ring illustration instead.
